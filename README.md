# DVBBet V3
MVP com identidade DVBBet, cadastro/login, créditos virtuais, jogos demonstrativos, histórico e código de indicação.

## Executar
Requer Node.js 18+.
1. `npm install`
2. `npm start`
3. Abra `http://localhost:3000`

## Publicação
Defina `SESSION_SECRET` em produção e use HTTPS, banco gerenciado, backups e monitoramento.

Esta versão não possui depósitos, saques ou apostas com dinheiro real.
